# Documentation Index

This directory is the only home for non-trivial project documentation.

## Sections

- `docs/current/`
  Active initiative documentation that is still changing.
- `docs/architecture/`
  Stable architecture documentation for behavior that already exists in code.
- `docs/adr/`
  Accepted architectural decisions.
- `docs/archive/`
  Historical and superseded material. Not active source of truth.

## Rules

- Do not add planning documents to the repository root.
- Do not treat archived material as current guidance.
- Move initiative docs from `docs/current/` into `docs/architecture/` or `docs/adr/` only after the implementation is stable.
- If documentation conflicts, prefer active initiative docs over archived docs.
