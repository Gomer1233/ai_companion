# Architecture Docs

This directory is for stable, implemented system documentation.

Use it for:

- architecture that already exists in code
- data flow and component boundaries that are no longer initiative-only
- long-lived technical references

Do not use it for:

- active refactor planning
- temporary migration notes
- per-PR execution checklists

Until the multichannel-core refactor is implemented, the active source of truth remains:

- `docs/current/multichannel-core/**`
