# Roadmap развития проекта

## 🔴 Критичные задачи (сделать в первую очередь)

### 1. Убрать дублирование между main.py и bot_lika.py
**Проблема**: Два файла по 3400 строк, отличаются только логикой для "whore" режима.

**Решение**: 
- Создать базовый класс `BaseBot` с общей логикой
- `main.py` и `bot_lika.py` наследуются от него
- Переопределяют только специфичную логику

**Время**: 1-2 дня

### 2. Вынести конфигурацию из кода
**Проблема**: Много констант хардкодятся в коде (MODEL_PRESETS, таймауты, лимиты).

**Решение**:
- Создать `config/settings.py` с использованием pydantic
- Все настройки через переменные окружения или config файл

**Время**: 0.5 дня

### 3. Разделить монолитные файлы
**Проблема**: Вся логика в одном файле (handlers, DB, LLM, изображения).

**Решение**: См. REFACTORING_PLAN.md

**Время**: 5-7 дней (поэтапно)

## 🟡 Важные улучшения

### 4. Добавить обработку ошибок
**Текущее состояние**: Базовые try/except, но нет централизованной обработки.

**Что сделать**:
- Создать декоратор для обработки ошибок в handlers
- Логирование всех ошибок с контекстом
- Graceful degradation при падении сервисов

**Время**: 1 день

### 5. Добавить валидацию входных данных
**Проблема**: Нет проверки входных данных от пользователя.

**Что сделать**:
- Валидация длины сообщений
- Санитизация текста
- Защита от спама/флуда

**Время**: 1 день

### 6. Улучшить систему логирования
**Текущее состояние**: Базовое логирование через logging.

**Что сделать**:
- Структурированное логирование (JSON)
- Разные уровни для разных компонентов
- Ротация логов

**Время**: 0.5 дня

## 🟢 Желательные фичи

### 7. Добавить тесты
**Что тестировать**:
- Unit-тесты для сервисов (LLM, изображения, TTS)
- Integration тесты для handlers
- Тесты для работы с БД

**Инструменты**: pytest, pytest-asyncio

**Время**: 3-5 дней

### 8. Добавить мониторинг и метрики
**Что добавить**:
- Метрики использования (prometheus)
- Трассировка запросов
- Алерты при ошибках

**Время**: 2-3 дня

### 9. Оптимизация работы с БД
**Проблемы**:
- Много прямых SQL запросов
- Нет connection pooling
- Нет кэширования

**Что сделать**:
- Использовать ORM (SQLAlchemy) или query builder
- Connection pooling
- Кэширование частых запросов (Redis)

**Время**: 2-3 дня

### 10. Добавить CI/CD
**Что настроить**:
- GitHub Actions для тестов
- Автоматический деплой
- Линтинг (ruff, black, mypy)

**Время**: 1 день
